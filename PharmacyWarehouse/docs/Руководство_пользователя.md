# Руководство пользователя

## 1. Установка и первый запуск
1. Установите **.NET 8 Desktop Runtime** (Windows).
2. Соберите и запустите: `dotnet run --project src/PharmacyWarehouse.UI` (или запустите собранный `PharmacyWarehouse.UI.exe`).
3. При первом запуске автоматически создаётся база данных `%LOCALAPPDATA%\PharmacyWarehouse\pharmacy.db`.
4. Войдите под учётной записью по умолчанию: логин `admin`, пароль `Admin123!`. **Сразу создайте своего администратора и смените пароль** (раздел 6), а стандартный заблокируйте.

## 2. Вход в систему
Введите логин и пароль, нажмите «Войти» (или Enter). После 5 неудачных попыток окно закрывается. Сообщение об ошибке не уточняет, что именно неверно (логин, пароль или блокировка) — это сделано намеренно.

## 3. Главное окно
Слева — разделы: «Товары», «Приход / расход», «Отчёты», «Пользователи» (только администратор), «Выйти из учётной записи». В центре — предупреждения о партиях, срок которых истёк или истекает в ближайшие 30 дней. Внизу — имя и роль текущего пользователя.

## 4. Работа с товарами
- **Добавить:** кнопка «Добавить» → заполните наименование (обязательно), остальные поля по желанию, цену → «Сохранить».
- **Изменить:** выберите строку → «Изменить» (или двойной щелчок).
- **Удалить:** выберите строку → «Удалить» → подтвердите. Товар, у которого есть партии, удалить нельзя — система сообщит об этом.
- **Поиск:** введите часть названия или действующего вещества в поле «Поиск».

## 5. Оформление прихода и расхода
1. «Приход / расход» → выберите **товар**, затем **партию**. Если партии ещё нет — «Новая партия…»: укажите номер серии, срок годности, начальный остаток.
2. Выберите тип: «Приход» или «Расход / списание», укажите количество и при необходимости комментарий.
3. «Выполнить». Остаток обновится, операция появится в списке «Последние операции».

Правила и сообщения об ошибках:
| Сообщение | Причина |
|---|---|
| «Количество должно быть больше нуля» | Введён 0 или отрицательное число |
| «Недостаточно товара в выбранной партии» | Расход больше остатка |
| «Партия просрочена: расход возможен только как списание…» | Для списания просроченного товара укажите причину в комментарии |
| «Нельзя оформить приход на партию с истёкшим сроком годности» | Просроченный товар принимать нельзя |
| «Партия с таким номером у этого товара уже существует» | Номер серии должен быть уникальным для товара |

## 6. Отчёты
«Отчёты» → таблица остатков по партиям. Цвет строки: **красный** — просрочено, **жёлтый** — истекает скоро, **серый** — нет в наличии. Поле «за, дней» меняет порог «истекает скоро» (по умолчанию 30), затем «Построить». «Экспорт в Excel…» сохраняет файл `.xlsx` (Microsoft Excel устанавливать не нужно). Если файл открыт в Excel, сохранить поверх него нельзя — закройте его.

## 7. Пользователи (только администратор)
- **Добавить:** логин (не короче 3 символов), пароль (не короче 6), ФИО, роль.
- **Блокировать / разблок.:** заблокированный пользователь войти не может. Нельзя заблокировать себя и последнего активного администратора.
- **Сменить пароль:** выберите пользователя → введите новый пароль.

## 8. Чек-лист ручной проверки перед защитой (на Windows)
- [ ] Вход `admin` / `Admin123!` проходит; неверный пароль — сообщение об ошибке.
- [ ] Администратор видит кнопку «Пользователи»; созданный фармацевт — нет.
- [ ] Товар: добавление, изменение, поиск, удаление (с партией — отказ).
- [ ] Партия создаётся; приход увеличивает, расход уменьшает остаток; расход больше остатка отклоняется.
- [ ] Отчёт подсвечивает просроченные и «истекающие» партии; экспорт открывается в Excel.
- [ ] При входе показывается предупреждение о партиях с истекающим сроком.
- [ ] Заблокированный пользователь не входит.

## 9. Резервное копирование
Скопируйте файл `%LOCALAPPDATA%\PharmacyWarehouse\pharmacy.db` при закрытом приложении. Восстановление — обратная подмена файла.
